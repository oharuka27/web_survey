# くらしのアンケート

QRコードからスマホで回答し、4問の集計をドーナツ型の円グラフで表示するWebアプリです。

## 起動

Node.js 22.13以上が必要です（Node.js 24推奨）。

```sh
npm install
npm start
```

集計画面: http://localhost:3000 ／ 回答画面: http://localhost:3000/vote

スマホとPCを同じWi-Fiに接続して、集計画面のQRコードを読み取ってください。QRコードにはPCのネットワークアドレスが自動で設定されます。複数のネットワークがある場合は、スマホからアクセスできるPCのIPアドレスを明示してください。

```sh
PUBLIC_URL=http://192.168.1.10:3000 npm start
```

インターネット経由で利用する場合は、サーバーに設置して `PUBLIC_URL=https://公開先のドメイン` を設定してください。ポートは `PORT` で変更できます。PCのファイアウォールでも使用するポートへの接続を許可する必要があります。

## 仕様

- 住みたい府県：滋賀県、京都府、大阪府、兵庫県、奈良県、和歌山県、三重県
- 世帯構成：1人、2人、3人、4人、それ以上
- 子供：いる、いない
- 自家用車：ある、なし
- 全問必須、各問1つ選択。集計は3秒ごとに更新。
- 回答は `data/survey.sqlite` に保存され、再起動後も保持されます。
- 同じブラウザーでは回答済み状態を保持し、同一送信トークンの再送は重複集計しません。本人認証はないため、別ブラウザーなどからの再回答を防ぐものではありません。
- 集計画面はアクセスできる全員に公開されます。
